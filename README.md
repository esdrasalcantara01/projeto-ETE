# Personalize

## Descrição

A Personalize é uma loja virtual voltada à venda de camisetas personalizadas de acordo com o gosto, a arte e o estilo do cliente. A proposta é atender às preferências de cada pessoa em relação à moda e ao seu visual.

## Objetivo

Oferecer maior liberdade de escolha na personalização de camisetas, diminuindo as limitações de modelos prontos. O projeto é voltado a pessoas que desejam vestir camisetas de acordo com seu próprio estilo.

## Funcionalidades implementadas

- Cadastro de usuários.
- Login de usuários.

## Funcionalidades previstas

- Compra de produtos.
- Atualização dos dados do perfil.
- Logout (sair da conta).

## Tecnologias utilizadas

- HTML.
- CSS.
- PHP.
- MySQL.

## Como executar

### Pré-requisitos

- Git instalado para clonar o repositório.
- Ambiente com PHP e MySQL configurados.

### Clonagem do projeto

Clone o repositório utilizando o Git:

```bash
git clone URL_DO_REPOSITORIO
```

Depois, acesse a pasta do projeto:

```bash
cd NOME_DA_PASTA
```

Substitua `URL_DO_REPOSITORIO` pelo endereço do projeto no GitHub e `NOME_DA_PASTA` pelo nome da pasta criada na clonagem.

### Configuração e inicialização

As instruções de configuração do banco de dados e inicialização do servidor PHP ainda precisam ser acrescentadas.
